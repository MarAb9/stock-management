# Stock movement UI contract
- Updated 2026-09-15 after completing the stock movement alignment slice.
- `frontend/src/app/pages/stock.component.ts` is now the stock workflow surface for entry, exit, return, transfer, adjustment, loss and disposal. It keeps stock authority backend-owned and only submits to `POST /api/stock/movements`.
- Backend contract remains `StoreMovementRequest` + `StockService`: quantity > 0 with max 3 decimals; performed_at cannot be future; adjustment requires direction; adjustment/loss/disposal require reason; transfer requires distinct source and destination; product lots/FEFO/expiry are enforced by StockService.
- UI behavior: entry/return/adjustment increase show destination; exit/loss/disposal/adjustment decrease show source; transfer shows both. Adjustment copy distinguishes positive and negative. Submit is disabled while saving, success uses the global snackbar, and backend field errors use the shared validation mapper with the stock location alias.
- Lot-managed product behavior: selecting a lot-tracked product loads `products/{id}/lots`, `products/{id}/balances`, and suppliers once. Entry supports new or existing lot; decreases support FEFO or explicit lot; return and positive adjustment require an existing lot. Lot labels include available quantity and expiry state; expired lots are only allowed for loss/disposal/adjustment.
- Movement history groups rows by `operation_reference` so multi-lot FEFO allocations display as one operation with a lot count badge and total quantity.
- Tests in `frontend/src/app/pages/stock.component.spec.ts` cover entry fields, transfer source/destination validation, adjustment direction behavior, lot-managed loading, backend validation mapping, and shared success feedback.
- Verification passed 2026-09-15: `cmd /c npm test -- --watch=false` 7 files / 24 tests; `cmd /c npm run build` passed. Angular still emits the existing Sass `@import` deprecation warning. Sandboxed Angular runs can fail with Windows esbuild `spawn EPERM`; use the approved elevated path.
